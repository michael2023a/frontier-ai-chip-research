# frontier-ai-chip-research

**AI 前沿产业研究：前沿大模型公司 × 芯片产业层 × 两者的交汇接缝。**

本仓库不是代码项目，是一套带纪律的研究笔记：**每条结论都可回溯到来源，每个数字都带口径与测试条件，冲突数据一律并列不换算。**

**先读 [`研究/00-课题地图与研究路径.md`](研究/00-课题地图与研究路径.md)**——它是整个课题的总纲：

- **§1 结算框架**：三条线收敛到的七个共享变量（每兆瓦 token 数 / 利用率 / KV 内存需求 / 元数据访存占比 / 域大小 / 编译器中间层 / 设计周期）+ 三个结算公式
- **§2 按变量重排的结论索引**：所有重要发现横向组织
- **§5 唯一研究标准**：分析单位、来源分级、**八类口径错误**固定检查项
- **§7 待续清单与观察线** / **§8 各线完整结论存档**

## 三条线的分析单位

| 线 | 分析单位 | 主问题 |
|---|---|---|
| A | 公司/实验室 | 谁最前沿最强？谁进步最快？ |
| A-2 | 机制/函数 | 进步是怎么产生的？2026 年换了什么输入？ |
| B | 产业层（7–8 层） | 每层的方法与格局？瓶颈在哪一层？ |
| A×B | **接缝** | 模型与硅在哪里互相锁定？ |
| C | **一条口径/序列** | 七变量中哪些正在成为公共度量？ |

## 研究纪律（摘要）

1. **来源分级必须标注**：【官方】>【一手三方】>【产业媒体】>【待验证】
2. **八类口径错误**（固定检查项）：宣布≠开工 / 合同≠收入 / 开关≠栈 / 模拟·论文≠生产 / 份额≠有效算力 / 算子≠系统 / 规范≠启用 / **自报≠可比**
3. **冲突数据并列，不替读者取舍**——量级差 3 倍的也同时写
4. **每个子课题留「尚未解决/待验证」清单**，宁可承认不知道
5. **检索用具体产物名，不构造抽象术语**；涉及中国的命题双语检索
