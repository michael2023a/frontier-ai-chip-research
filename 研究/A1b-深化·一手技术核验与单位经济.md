## 1. 一手技术核验

### 1.1 OpenAI · GPT-6 Astra【官方系统卡，2026-09-03】

**规格（官方模型页）**
- 上下文 **1,050,000 token**；最大输出 128K；知识截止 2026-04-30
- 推理档位：low / medium / high / xhigh / **max**（Sol 时代最高是 max，Astra 保留五档）
- 输入文本+图像，输出文本（不支持音频/视频）；不支持微调
- 定价：输入 $10/M、输出 $50/M、缓存命中 $1/M；Fast 模式 2× 速度 2× 价格

**训练（系统卡 + 发布会口径）**
- 官方自述：**"迄今最大规模的训练 run"**，首次在德克萨斯 Stargate 站点用 **超过 10 万张 GPU** 预训练（研究副总裁 Aidan Clark 原话："the first time we've pre-trained on more than 100,000 GPUs"）
- **首次让前代模型在训练监督中发挥重要作用**（递归式自我改进 RSI 的雏形）
- **对齐改进贯穿全链路**：从预训练数据的成分构成，到 RL 阶段的打分（grading）——不是只在最后加安全层
- 用 **54,000+ 条内部 Codex 任务做部署仿真**，Astra 的高危不当行为标记数约为 Sol 的 **一半**
- **训练曾中断两周**：2026 年 8 月的 OpenAI–Hugging Face 安全事件后，暂停部分前沿训练以加固隔离与网络管控、扩大监控、提高对齐要求；最大的一次前沿 RL run 搁置到 8 月 28 日。新增监控开销约为被监控推理算力的 **20%**（这是一个此前没人算的成本项）
- 安全分级：**首个在 Preparedness Framework 下达到网络安全"Critical"能力级别**的模型

**架构（传闻，须打折扣）**
The Information（2026-09-01）与 Sebastian Raschka 的分析称 Astra 采用 **looped / recurrent-depth Transformer**（token 多次穿过同一组层，权重复用）；首席科学家 Jakub Pachocki 确认其计算图深度"在 GPT-4 的 2 倍以内"。视觉侧有报道称 **MoVA（Mixture of Vision Agents）**多视觉智能体路由。
→ **OpenAI 未发布技术报告、未披露参数量**，以上均为二手，**标为待验证**。

**基准（厂商自报，与第三方口径有冲突）**
Terminal-Bench 4.0 = 57.9%（OpenAI 口径）vs 59.1%（Artificial Analysis 口径）——**同一指标两个数字，并列标注**；FrontierMath Tier 4 = 97.6%；GPQA Diamond = 96.0%；ARC-AGI-3 = 99.9%；OSWorld 2.0 = 72.6%；ExploitBench 满分并发现 2 个 0day。

**成本主张**：官方称在 DeepSWE v1.1 上"每任务 API 成本比 Sol 低 32%"（有媒体据预沟通材料写成 57%，口径分歧）；AA v4.3 的实测是 **同分下 Astra $3.26/任务 vs Fable 5.1 $7.63/任务（便宜 57%）**。

### 1.3 Kimi K3 · 目前信息最完整的开源旗舰【官方技术报告，2026-07-27/28】

**架构（技术报告原文口径）**
- **2.88T 总参数 / 1040 亿激活**（部分报道写 2.8T，属同一数量级）
- **Stable LatentMoE**：896 个路由专家，每 token 激活 16 个（**56× 稀疏比**）；用 **Quantile Balancing**（从路由分数分位数直接推导分配，去掉启发式更新与敏感超参）+ **SiTU-GLU** 保持训练稳定
- **KDA + Gated MLA = 3:1 混合注意力**（Kimi Delta Attention 处理长序列，Gated MLA 保留全局精确检索）；官方称百万 token 上下文下解码最快 **6.3×**
- **Attention Residuals（AttnRes）**：跨深度选择性检索表示而非均匀累积，官方称训练效率 **+25%**、额外成本 **<2%**
- **Per-Head Muon**：逐注意力头独立做 Muon 正交化
- **MoonViT-V2 视觉塔**：0.4B，**从零用 next-token prediction 训练**（而不是主流视觉编码器用的对比学习），官方称效果追平 SigLIP 初始化基线且梯度更稳（报告中给了梯度范数对比图）
- **后训练：Joint RL + MOPD**——训练 9 个按领域与 effort 级别专门化的策略，再合并成单一发布模型
- **量化**：从 SFT 阶段起做量化感知训练，**MXFP4 权重 + MXFP8 激活**（为跨硬件兼容）；官方推荐 **≥64 加速器的 supernode** 配置

**开源了训练基础设施（不是只放权重）**
- **MoonEP**：超大规模 MoE 的专家并行通信库
- **FlashKDA**：KDA 的 CUTLASS 实现，H20 上 prefill 比 flash-linear-attention 基线快 **1.72–2.22×**；已向 vLLM 贡献实现（KDA 对前缀缓存是新问题）
- **AgentEnv**（与 kvcache-ai 合作）：分布式 agent 环境，支持快速快照/恢复/fork，支撑 K3 自身的 agentic RL

**基准（官方，全部 max effort）**：Terminal-Bench 2.1 = 88.3（GPT-5.6 Sol 88.8、Fable 5 88.0）；BrowseComp = 91.2（Sol 90.4、Fable 5 88.0）；GPQA-Diamond = 93.5；**SWE-Marathon = 42.0（Fable 5 35.0、Sol 39.0）**；WebDev Arena 登顶 1679 Elo（首个夺冠的开源模型）。整体仍略逊 Fable 5 与 GPT-5.6 Sol。

**两个超出"模型能力"范畴的信号（重要）**
1. **GPU 内核优化**：24 小时内独立完成 AttnRes / DeepSeek Sparse Attention / KDA / MLA 四种内核优化——AttnRes 延迟 283.6ms → **114.4ms**，DSA 与 KDA 运行时间分别减少 **55.1% / 73.6%**，MLA 接近峰值 TFLOPS。该表现**与 Claude Fable 5 持平，优于 Opus 4.8 / GPT-5.6 Sol / GPT-5.5**。测试环境同时覆盖 NVIDIA H200 和**其他供应商的 GPGPU**——意味着部署能力不锁在 NVIDIA 生态。
2. **自研芯片原型**：48 小时自主运行中，基于开源 EDA 工具与 Nangate 45nm 工艺库，完成一款推理芯片原型的设计、优化与验证——**13 个模块、3.981 mm²、100MHz 下 8721 tok/s**，带 INT4 MAC 融合去量化。还自研了 **MiniTriton** 编译器（Python 前端到 PTX 全链路由模型完成，L20 上超过 PyTorch eager / torch.compile / Triton）。
→ **这是 A 线与 B 线的交汇点**：模型公司开始反向进入编译器与芯片设计。

**许可（务必注意）**：MIT 风格但**不是纯 MIT**——可复制/修改/部署/微调/分发/再许可/销售；但若使用者或其关联方经营 MaaS 业务且连续 12 个月合计收入 **超过 $2000 万**，商用前须与月之暗面签单独协议；若搭载产品超过 1 亿 MAU 或月收入超 $2000 万，须在界面显著展示"Kimi K3"。
**传播**：上线 30 分钟内登顶 Hugging Face 趋势榜、4000+ 赞，HF CEO 称是平台史上最快增长。

### 1.4 GLM-5.3 / 5.3-Flash · "纯后训练"的最强证据【z.ai 官方博客】

**核心事实（官方原文）**：**GLM-5.3 使用与 GLM-5.2 完全相同的基座模型，全部增益来自后训练。**没有改预训练权重。

- 基座（据配置与二手整理）：MoE，约 **744B 总参数 / 40B 激活**；配置文件显示 78 层、256 路由专家 + 1 共享专家、每 token 激活 8 个、上下文 1,048,576 token
  ⚠️ 冲突：有中文来源称 5.3 上下文"回调至 200K"（算力重投代码/工具/安全），与配置文件的 1,048,576 冲突——**并列标注，待一手确认**
- 权重于 **2026-08-28** 发布（FP8 与 BF16 两个版本），许可为自定义 **GLM-5.3 License**：MIT 式自由，但若关联方 MaaS 业务 12 个月合计收入 **超过 $100 亿**，商用前须通过 Z.AI 安全审查

**环境与后训练方法（本轮最有价值的一段）**
- 三件套：**IndexShare**（长上下文处理）、**SAO with compaction**（长程 RL）、开源 **slime**（大规模异步训练框架）；新的调度/缓存/负载感知配置把端到端 RL 吞吐提升 **>2.3×**
- **环境合成流水线**：研究 agent 从真实工作中收集任务模式 → 转成带多步依赖与隐藏状态的可运行长程环境 → **judge agent 先试做一遍，验证任务确实可解** → 合成 verifier（**不给参考解**），用 solver 轨迹反向发现并堵住 reward shortcut → 通过 oracle / no-op / 未解状态三项检查的 verifier 才产出可直接训练的二值奖励
- 环境已从"编码练习"升级为**若干天工作量的真实专家任务**（例如给定与工程师相同的工作环境：算力集群、存储、内部文档、代码库、实验记录，要求诊断训练栈瓶颈、实现优化、跑实验、交付可度量的端到端加速）

**跃升幅度**：Terminal-Bench 3.0 **4.6 → 28.3**；DeepSWE v1.1 **46.2 → 66.9**；Agents' Last Exam **23.8 → 28.5**；ExploitBench **24.4 → 54.4**；CyberGym 84.5（漏洞发现 SOTA）。官方另称 Z.ai Code Bench 上比 5.2 提升 **50%**，且**同时降低 token 消耗**（Max 档 34.5% / 约 75K 输出 token，对比 5.2 的 23.4% / 96K）。

**"涌现的网络攻击能力"与安全争议（必须写）**
官方原话："As we scaled post-training, cyber capability developed faster than we expected."高危攻击相关能力将采用受信访问机制管控、**不完全随开源权重释放**。
第三方批评（csidia，2026-08-28）：模型卡列了 **16 个基准，其中 0 个与安全相关**——没有一项测量抗滥用、拒绝一致性或事实可靠性；语言字段只声明 en/zh。另：NIST 下属 CAISI 在 2026-07-17 对 GLM-5.2 的独立评估发现——**直接提问时模型会拒绝大多数攻击请求，但同样的任务一旦交给持有工具的 agent，它一个都不拒绝**。

**GLM-5.3-Flash（08-26，MIT 权重）**：**320B 总参 / 18B 激活**，45 层，**KDA 线性注意力层与 NoPE 稀疏 MLA 层交错**，8/288 专家，IndexPool 键值压缩；比 5.3 **注意力计算少 3.01×、KV cache 小 4.44×**；AA v4.1.1 = **57 分（109 个模型中第 3）**。

**Nathan Lambert（Interconnects）对"中国实验室怎么跟上的"的解读**：不是靠蒸馏，而是——按天计（而非按月）的发布周期、融资压力下对公开基准的强优化、对高价值场景（编码）的窄 specialization、**正在成型的国内 RL 环境数据产业**、以及组织人才与算力效率。

## 2. 单位经济：低价到底是效率还是补贴？

这一节回答 A2（进步最快）能否持续。

### 2.1 成本曲线：确实在快速下降（这是效率的部分）

- 企业级 AI 工作负载的**混合成本**：2025-04 的 **$18.40/百万 token** → 2026-04 的 **$6.07/百万 token**，**一年降 67%**
- NVIDIA MLPerf 数据：同一套 GB300 运行 DeepSeek-R1，靠 TensorRT-LLM、投机解码与并行优化，**半年内服务器场景吞吐提升 2.7 倍，单位 token 成本下降超过 60%**
- 工程侧的效率来源（各家技术报告里都能对上）：MoE 极端稀疏（K3 的 56×）、线性/混合注意力（KDA、Gated DeltaNet）、低精度（MXFP4/FP8 + QAT）、前缀缓存（K3 官方称代码任务缓存命中率 **>90%**）、prefill/decode 解耦、投机解码
- **Qwen3.8-Flash 训练成本较上代降近 90%**——这是"效率"最直白的一条证据

### 2.2 但物理成本有硬地板（这是补贴的部分）

**摩根士丹利模型（2026-07-28）**：一座 1GW AI 工厂，部署 410,256 张 GB300，总投资 **$390 亿**（IT 设备 $230 亿 + 供电/冷却/建筑 $160 亿）；IT 按 5 年折旧、非 IT 按 15 年折旧 → 年折旧 **$57 亿**，电力及其他运营 **$20 亿**。
结论：**在 75% 商业利用率下，每百万 token 至少要卖到约 $0.44 才能覆盖设备折旧、电力和基础运营成本。**
→ 对照：OpenAI 把 GPT-5.6 Luna 降价 80% 后的综合价约 **$0.31/百万**（按 8:1 输入输出比），若吞吐与大摩假设相同，需要 **107% 利用率**才能回本，或维持 75% 利用率时**吞吐再提高约 43%**。
（注：小模型实际吞吐可能远高于大摩测试的万亿参数模型，缓存与软件优化也会压低成本，所以**这不能证明 OpenAI 在亏本卖**——但它量化了"地板在哪"。）

**国内团队的 8 卡 B300 模型**：投资 ¥1500 万，8 万 token/s，利用率 80%，结算 ¥4/百万 token → 月收入约 ¥66.4 万，电费约 ¥3000，IDC ¥5 万，**按 3 年折旧**月摊 ¥41.7 万 → 月经营利润约 ¥19.4 万，ROIC 约 12%；**盈亏平衡利用率 56.5%**。

**两份模型 ROI 差近 4 倍，差异来自四个变量**：有效吞吐（1 万 vs 2750 token/s/卡）、商业利用率、token 净价、折旧年限（3 年 vs 5 年，仅改折旧就能让账面 ROIC 接近翻倍）。

**大摩给的三档 ROIC**：自建算力卖自有模型 API ≈ **46%** ＞ 出租 GPU ≈ **31%** ＞ 租第三方算力卖 API ≈ **25%**。
→ **"模型 + 算力 + 客户入口"越完整，越能把技术降本真正转化为投资回报**——这正好解释了为什么 Google（自研 TPU + 云 + 模型）能打价格战。

### 2.3 定价行为已经 K 型分化（这才是真实答案）

| 方向 | 玩家 | 动作 |
|---|---|---|
| **提价/变现派** | 智谱 | GLM 一季度 API 整体提价 **83%**，年内又连续数次（5 系列 +30% / Turbo +20% / 5.1 +10%）；CEO 张鹏称提价后 **API 调用量反而暴增 400%** |
| | 腾讯云 | HY2.0 Instruct API 价格上调 **463%**（2026-03-11），5 月起算力/容器/EMR 再 +5% |
| | 阿里云 | AI 算力与存储涨价 **5%–34%**（CPFS 智算版 +30%），并对 DataWorks 缩减免费额度 |
| | **DeepSeek** | 7 月中旬起**峰谷定价**（工作日 9–12/14–18 点价格翻倍）；**8-06 发布"整体大幅涨价预告"** |
| **低价清场派** | 字节（豆包/火山）、MiniMax、零一万物 | 凭集团算力与流量底座，仍在绝对低单价区间继续清场 |

**DeepSeek 这一条最说明问题**，它的两面必须一起看：
- **动因一（60–70%，资本）**：7-14 启动科创板 IPO 筹备（最快 2026 年底递表、2027 上市）；6-17 监管将科创板第五套标准扩至 AI 行业；7-15 启动第二轮融资，投前估值 **¥4800 亿**、投后 ¥5000 亿，拟募至多 ¥500 亿。当前 **ARR 约 $4–5 亿**（约 ¥29–36 亿）——对资本市场而言变现效率不够看。梁文锋内部说法：API 基准定价模型是"**购置设备后十个月回收成本**"，且"即便价格翻倍，对真正高频生产级调用量的影响也微乎其微"
- **动因二（30–40%，物理）**：8-01 DeepSeek V4-Flash 单日处理 **8 万亿 token**（5 万亿免费 + 3 万亿付费）；7-27 至 8-02 OpenRouter 全球周榜第一（7.22 万亿 token）；部分重度开发者单次调用消耗达 14.4M token；**8-04 API 大面积卡顿/短暂宕机**。国内 2026 Q1 算力需求 **+417%**、供给仅 **+128%**，H100 租赁价 **+40%**
- **结论**：低价不只是效率，是**生态位争夺**；一旦资本目标（IPO）和物理天花板同时到来，价格就会反弹。这也意味着"中国厂商永远便宜"是个错误假设。

**另外两条定价动作**：
- OpenAI 7-31：**Luna 输入/输出同时降价 80%**（输入 $0.2/M、输出 $1.2/M），Terra -20%，Sol 维持原价并推出 **Fast 模式（最高 2.5× 速度、2× 价格）**——典型的按能力与速度重新切分支付意愿
- Kimi K3：官方 API **并不便宜**（缓存命中 $0.3 / 输入 $3 / 输出 $15 每百万），但开放权重让小型算力运营商也能供给 → **开源在这里的作用不是降价，而是扩大供给并压低闭源溢价**

### 2.4 本节结论

> **中国的低价 ≈ 50% 工程效率 + 50% 战略补贴，且两部分都在快速变化。**
> 能持续的那一半：MoE 极端稀疏、线性/混合注意力、低精度 QAT、缓存与解耦推理、RL 环境规模化——这些写进了技术报告，是真实的。
> 不能持续的那一半：峰谷定价、8-04 的宕机、417% vs 128% 的供需缺口、DeepSeek 的涨价预告——这些说明算力物理成本与资本回报压力已经压到定价上了。
> **判断一家公司能否长期便宜，看它的低价来自架构效率还是资产负债表和融资节奏。**目前证据支持：**智谱、月之暗面、阿里偏"效率 + 战略亏损"，字节/MiniMax 偏"流量与算力补贴"**。

## 3. A 线结论修订（覆盖 `01` 的相应部分）

1. **"最强"与"最该用"已经分离**：Anthropic 侧 Opus 5（$5/$25）在中性基准上反超 Fable 5（$10/$50）；OpenAI 侧 Sol 维持原价而 Luna 降价 80%。**未来选型的关键是"每任务成本"，不是"榜单名次"**——Artificial Analysis 与 OpenAI 都已经在按 cost-per-task 说话。
2. **进步最快的机制解释已明确**：不是蒸馏，而是 **① 环境规模化后训练**（GLM-5.3 同基座纯后训练，Terminal-Bench 3.0 从 4.6 涨到 28.3，是最强单点证据）；**② 架构效率**（K3 的 56× 稀疏 + KDA + Per-Head Muon）；**③ 按天计的发布节奏**。
3. **开源与闭源的差距已经压到"个位数百分点"**：K3（2.88T）在 SWE-Marathon、BrowseComp、AutomationBench 上超过 Fable 5 与 GPT-5.6 Sol；GLM-5.3（753B，约为 K3 的 1/4 规模）在多个 agentic 编码项上打平或超过二者。**"规模"已不再是能力差距的主因，后训练与架构才是。**
4. **新变量：模型公司开始反向进入芯片与编译器层**——Kimi K3 自主优化 GPU 内核（表现与 Fable 5 持平）、自研 MiniTriton 编译器、48 小时设计出推理芯片原型。**这是 A 线与 B 线的交汇点，值得单开一条观察线。**
5. **安全与商业化正在成为新的分水岭**：OpenAI 因 Hugging Face 事件暂停前沿训练两周、新增约 20% 监控算力开销；GLM-5.3 因"涌现攻击能力"对高危部分做受信访问控制、且模型卡 16 个基准无一测安全。**能力越强，合规成本越高。**
